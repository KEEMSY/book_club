# Phase 12 — 독서 경험 심화 & 수익화 확대

## 1. 배경

Phase 11(`v0.8.0`)에서 리텐션·소셜피드·클럽발견·IAP·APM 인프라까지 완성했다.
APM(Prometheus/Grafana/Sentry) 구축으로 실 트래픽 가시성이 생겼고,
IAP 쉴드 구매·A/B 실험 인프라로 수익화 기반이 마련됐다.

**Phase 12의 전략적 맥락**:

1. **독서 노트 소셜화** — M14에서 `post_highlights` 테이블과 인용 카드 기반을 구축했다.
   이제 SNS 공유·피드 노출·다른 사용자 반응 연결로 바이럴 유입 엔진을 만든다.
2. **클럽 AI 코치** — 클럽 내 독서 계획 자동 생성·진도 알림·코칭 카드로
   클럽 체류 시간을 높이고 Pro 전환 유인을 강화한다.
3. **Pro 연간 플랜** — M43 A/B 실험(가격 표시)이 누적됐으니 연간 구독 옵션을 추가해
   LTV를 높인다.
4. **책 리뷰 & 평점** — 사용자 생성 콘텐츠를 자산화하고 SEO 기반을 다진다.
5. **안정화 스프린트** — APM 데이터 기반 실제 병목 해소, 크래시·에러율 SLO 달성.

## 3. M51 — 독서 노트 & 하이라이트 소셜 공유

### 3.1 목표

M14에서 구현한 `post_highlights` (비공개 인용 저장)를 소셜 레이어와 연결한다.
하이라이트를 피드에 공유하거나 SNS로 내보내면 독서 경험이 바이럴 콘텐츠가 된다.

### 3.2 비즈니스 규칙

- 하이라이트 공개 설정 (`visibility: private | followers | public`).
- 공개/팔로워 공개 하이라이트는 **팔로우 피드**에 `highlight` 타입 이벤트로 노출.
- 하이라이트 카드 UI: 책 표지 썸네일 + 인용 텍스트 + 페이지 번호 + 저자.
- **SNS 공유**: `share_plus`로 이미지 캡처 공유 (RepaintBoundary 래핑).
- 다른 사용자가 하이라이트에 ❤️ 리액션 가능 (M47 feed_event_reactions 재사용).
- 내 하이라이트 목록: `GET /me/highlights?book_id=&page=` — 페이지네이션.
- 공개 하이라이트 탐색: `GET /highlights/explore?sort=recent|popular` (최대 50건).

### 3.3 DB 변경

```sql
-- 기존 post_highlights 테이블에 visibility 컬럼 추가
ALTER TABLE post_highlights
    ADD COLUMN visibility VARCHAR(16) NOT NULL DEFAULT 'private',
    ADD COLUMN shared_at  TIMESTAMPTZ;

CREATE INDEX idx_highlights_public ON post_highlights(created_at DESC)
    WHERE visibility = 'public' AND deleted_at IS NULL;
```

### 3.4 백엔드 API 변경

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/me/highlights` | 내 하이라이트 목록 (book_id 필터, 페이지네이션) |
| PATCH | `/me/highlights/{id}` | visibility 변경 |
| GET | `/highlights/explore` | 공개 하이라이트 탐색 (recent/popular) |
| POST | `/me/highlights/{id}/share` | 피드 이벤트 발행 + shared_at 기록 |

- `feed_events`에 `HIGHLIGHT_SHARED` 이벤트 타입 추가.
- `FeedService.publish_highlight()` — 중복 발행 방지 (shared_at이 이미 있으면 skip).

### 3.5 모바일 변경

- **`HighlightFeedCard`**: 피드에 인용 카드 노출 (배경색: 책 표지 dominant color 샘플링).
- **`MyHighlightsScreen`**: 내 하이라이트 목록 + visibility 토글 + SNS 공유 버튼.
- **`HighlightExploreScreen`**: 공개 하이라이트 탐색 탭 (탐색 탭 내 섹션).
- **`TimerScreen`**: 독서 중 형광펜 버튼 → 하이라이트 저장 시트 (페이지·텍스트 입력).

## 4. M52 — 클럽 AI 독서 코치

### 4.1 목표

클럽 관리자가 AI 기반 독서 계획을 자동 생성하고,
멤버에게 진도 알림·코칭 카드를 발송해 클럽 활성도를 높인다.

### 4.2 비즈니스 규칙

- **독서 계획 자동 생성**: 책 총 페이지 ÷ 목표 완독 기간(주) → 주간 목표 페이지.
  - 기간 옵션: 2주 / 4주 / 8주.
  - 클럽 관리자가 계획 생성 → 멤버에게 FCM 발송.
- **진도 알림**: 매주 월요일 09:00 KST, 지난 주 진도가 목표 대비 80% 미만인 멤버에게 푸시.
- **코칭 카드**: 매주 클럽 공용 채팅방에 AI 생성 독서 가이드 카드 자동 게시
  (큐레이션 카드 API 재사용).
- Pro 구독자 클럽장만 AI 코치 기능 활성화 (Pro 전환 유인).

### 4.3 DB 변경

```sql
CREATE TABLE club_reading_plans (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    club_id UUID NOT NULL REFERENCES clubs(id) ON DELETE CASCADE,
    book_id UUID NOT NULL REFERENCES books(id),
    start_date DATE NOT NULL,
    end_date DATE NOT NULL,
    weekly_pages INT NOT NULL,
    created_by UUID NOT NULL REFERENCES users(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_club_plans_club ON club_reading_plans(club_id);

ALTER TABLE club_members
    ADD COLUMN current_page INT NOT NULL DEFAULT 0,
    ADD COLUMN last_page_updated_at TIMESTAMPTZ;
```

### 4.4 백엔드 API 변경

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/clubs/{id}/reading-plan` | 독서 계획 생성 (Pro 클럽장 전용) |
| GET | `/clubs/{id}/reading-plan` | 현재 독서 계획 조회 |
| PATCH | `/clubs/{id}/members/me/progress` | 내 현재 페이지 업데이트 |
| GET | `/clubs/{id}/progress` | 전체 멤버 진도 현황 |

### 4.5 모바일 변경

- **클럽 상세 화면**: "독서 계획" 탭 추가 — 주간 목표·전체 진도 바.
- **`ReadingPlanSetupSheet`**: 클럽장 전용 계획 생성 BottomSheet.
- **진도 업데이트**: 독서 세션 종료 시 "오늘 몇 페이지까지 읽었나요?" 팝업.

## 5. M53 — Pro 연간 플랜 + 고급 통계

### 5.1 목표

월간 구독(6,900원)에 더해 **연간 구독(59,000원, 월 4,916원 = 약 29% 할인)**을 추가한다.
고급 통계(독서 속도 트렌드, 장르 분포, 연간 비교)로 Pro 체감 가치를 높인다.

### 5.2 비즈니스 규칙

- RevenueCat에 연간 상품 추가 (`annual_pro_59000`).
- 페이월 UI: 월간/연간 토글 탭, 연간 선택 시 "가장 인기" 배지.
- **고급 통계** (Pro 전용):
  - 독서 속도 트렌드 (분/페이지, 최근 4주 추이).
  - 장르 분포 파이 차트.
  - 올해 vs 작년 독서량 비교.
  - 독서 연속 최장 기록.
- 연간 구독자에게 쉴드 3개 웰컴 선물 (구매 webhook에서 지급).

### 5.3 DB / 백엔드 변경

- `subscription_events` 테이블에 `annual_pro_59000` 상품 처리.
- `GET /me/stats/advanced` — Pro 전용 고급 통계 엔드포인트.
- RevenueCat webhook: `INITIAL_PURCHASE` + `annual_pro` → 쉴드 3개 지급.

### 5.4 모바일 변경

- `PaywallScreen` 개편: 월간/연간 세그먼트 컨트롤.
- `AdvancedStatsScreen`: 고급 통계 화면 (Pro 게이트 적용).
- 통계 탭에 "Pro 전용 고급 통계 보기" CTA 추가.

## 6. M54 — 책 리뷰 & 평점 시스템

### 6.1 목표

완독 후 별점(1–5)과 한 줄 리뷰를 남길 수 있게 한다.
사용자 생성 리뷰는 책 상세 페이지에 노출되어 콘텐츠 자산이 된다.

### 6.2 비즈니스 규칙

- 리뷰는 **완독(`status=completed`)한 책만** 작성 가능.
- 1인 1리뷰 (수정 가능, 삭제 가능).
- 별점 1–5 (0.5 단위), 리뷰 텍스트 최대 500자.
- 책 상세 페이지: 평균 평점 + 평점 분포 바 + 최신 리뷰 5건.
- 신고 기능 (5회 이상 신고 시 자동 숨김).
- 피드 이벤트: `BOOK_REVIEWED` — 팔로워 피드에 리뷰 카드 노출.

### 6.3 DB 변경

```sql
CREATE TABLE book_reviews (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    book_id UUID NOT NULL REFERENCES books(id) ON DELETE CASCADE,
    rating NUMERIC(2,1) NOT NULL CHECK (rating >= 1.0 AND rating <= 5.0),
    body TEXT,
    report_count INT NOT NULL DEFAULT 0,
    hidden_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE(user_id, book_id)
);
CREATE INDEX idx_reviews_book ON book_reviews(book_id, created_at DESC)
    WHERE hidden_at IS NULL;
```

### 6.4 API 변경

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/books/{id}/reviews` | 리뷰 작성 |
| PATCH | `/books/{id}/reviews/me` | 내 리뷰 수정 |
| DELETE | `/books/{id}/reviews/me` | 내 리뷰 삭제 |
| GET | `/books/{id}/reviews` | 책 리뷰 목록 (페이지네이션) |
| POST | `/books/{id}/reviews/{review_id}/report` | 리뷰 신고 |

### 6.5 모바일 변경

- `BookDetailScreen`: 평균 평점 위젯 + 리뷰 섹션 추가.
- `WriteReviewSheet`: 별점 슬라이더 + 텍스트 입력 BottomSheet.
- `ReviewFeedCard`: 피드에 리뷰 카드 노출.

## 7. M55 — 안정화 & UX 개선 스프린트

### 7.1 목표

APM(Sentry/Prometheus) 데이터 기반으로 실제 발생하는 오류와 성능 병목을 해소한다.
크래시율 ≤ 0.5%, 에러율(5xx) ≤ 0.1% SLO를 달성한다.

### 7.2 구현 범위

- Sentry 오류 트리아지 — 상위 5개 오류 원인 파악 후 수정.
- P99 응답 200ms 초과 엔드포인트 쿼리 최적화 (N+1 쿼리, 인덱스 누락 점검).
- Flutter 크래시 리포트 분석 + 상위 3개 수정.
- **UX 개선**:
  - 로딩 상태 스켈레톤 UI 전체 적용 (현재 일부 누락).
  - 오프라인 상태 배너 + 재시도 버튼.
  - 빈 상태(empty state) 일관성 정비.
- 접근성 Semantics 누락 위젯 보완 (`dart analyze` 경고 0 유지).
