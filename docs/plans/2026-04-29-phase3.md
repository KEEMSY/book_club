# Book Club — Phase 3 구현 계획

## 1. 배경 및 목표

Phase 2(M7–M11)에서 커뮤니티 탭·소셜 그래프·챌린지 시스템·알림 확장이 완성됐다.
챌린지 시스템은 UI와 백엔드 구조는 있지만 진행도 자동 갱신(evaluate_progress)이 미연결인 상태다.

Phase 3의 핵심 목표:

1. **챌린지 완성**: reading 이벤트에 evaluate_progress를 연결해 챌린지 진행도가 실제로 쌓이도록 한다.
2. **위시리스트**: 읽고 싶은 책을 저장하고 팔로워와 공유한다.
3. **하이라이트·메모**: 책을 읽으며 특정 구절을 저장하고 커뮤니티에 공유한다.
4. **QA·폴리시·출시 준비**: 앱스토어 제출 전 전체 흐름 검증.

## 3. M12 — 챌린지 달성 판정 + 시드 스크립트

### 3.1 목표

`ChallengeService.evaluate_progress` 를 실제 reading 이벤트에 연결해,
타이머 세션 완료·완독·스트릭 갱신 시 자동으로 챌린지 진행도가 쌓이도록 한다.

### 3.2 추가할 이벤트

**`book/events.py` 신설:**

```python
@dataclass(frozen=True, slots=True)
class UserBookCompleted:
    user_id: UUID
    user_book_id: UUID
    book_id: UUID
```

`BookService.update_status` 가 `COMPLETED` 로 전환할 때 스테이징.

### 3.3 evaluate_progress 구현

`ChallengeService` 에 세 핸들러 추가:

| 핸들러 | 구독 이벤트 | 대상 챌린지 타입 |
|---|---|---|
| `on_reading_session_completed` | `ReadingSessionCompleted` | `reading_time` (duration_sec 누산) |
| `on_user_book_completed` | `UserBookCompleted` | `books_count` (+1) |
| `on_grade_recomputed` | `UserGradeRecomputed` | `streak` (streak_days 최대값 갱신) |

진행도 갱신 후 `current_value >= target_value` 이면 `award_badge` 호출.
이미 달성한 챌린지(achieved_at != None)는 재판정 생략.

### 3.4 시드 스크립트

`backend/scripts/seed_challenges.py`:
- 예시 챌린지 3개: 30일 읽기(reading_time), 책 5권 완독(books_count), 30일 스트릭(streak)
- 각 챌린지에 배지 연결
- `upsert` 기반 멱등 설계

### 3.5 어드민 API

```
POST /admin/challenges   — 챌린지 생성
POST /admin/badges       — 배지 생성
```

`X-Admin-Key` 헤더 인증 (env var `ADMIN_KEY`). 미설정 시 404 반환.

### 3.6 테스트

- `on_reading_session_completed`: reading_time 챌린지 진행도 갱신 및 달성 시 badge awarded
- `on_user_book_completed`: books_count 챌린지 진행도 갱신
- `on_grade_recomputed`: streak 챌린지 진행도 갱신
- 이미 달성한 챌린지는 재갱신 없음
- 어드민 API: 유효 키 → 201, 무효 키 → 403

## 4. M13 — 위시리스트

### 4.1 백엔드

- `UserBookStatus` 에 `WISHLIST = "wishlist"` 추가 + Alembic 마이그레이션
- `PATCH /books/user-books/{id}/status` 로 wishlist 전환 허용
- `GET /books/library?status=wishlist` 로 위시리스트 조회

### 4.2 모바일

- 서재 탭에 "읽고 싶어요" 탭 추가 (읽는 중 / 완독 / 읽고 싶어요 3탭)
- 책 검색 결과·책 상세에서 "읽고 싶어요" 버튼
- 위시리스트 아이템 → 프로필에서 공개 설정 시 팔로워 피드에 공유 가능

## 5. M14 — 하이라이트·메모

### 5.1 데이터 모델

`feed` 도메인 내 새 테이블 `post_highlights`:

```
post_highlights
  id          UUID PK
  user_id     UUID FK(users)
  user_book_id UUID FK(user_books)
  quote_text  TEXT      -- 인용문 (최대 500자)
  page_number INT NULL  -- 페이지 번호 (선택)
  created_at  TIMESTAMPTZ
```

`post` 의 `post_type` 에 `highlight` / `memo` 추가.
`Post.highlight_id` → `post_highlights.id` FK (NULL 가능).

### 5.2 백엔드

- `POST /books/user-books/{id}/highlights` — 하이라이트 저장
- `GET /books/user-books/{id}/highlights` — 내 하이라이트 조회
- `POST /community/books/{book_id}/posts` 에 `post_type=highlight` 지원

### 5.3 모바일

- 책 상세 화면 하단 "하이라이트 추가" 버튼
- 인용문 + 페이지 입력 모달
- "피드에 공유" 토글 → PostComposeScreen 으로 이어지거나 바로 publish
- 피드 PostCard 에 `highlight` 타입 렌더링 (인용 스타일 카드)
