# Phase 14 — 공개 출시 & 그로스 엔진

## 1. 배경

Phase 13(`v0.1.0`)에서 소프트 런치(TestFlight + Google Play 내부 테스트)를 완료했다.
이제 앱스토어 공개 출시로 전환하면서, 사용자 유입을 자급자족하는 그로스 루프를 구축한다.

**Phase 14를 추동하는 시장 신호 (2026-06-21 딥리서치 3차 확인)**:

1. **Everand + Fable 단일 구독 런칭 (2026-06-02)** — 500만 커뮤니티, Fable의 AI 독서 분석·Scout 추천이 글로벌 콘텐츠 플랫폼과 결합됐다. 한국어·국내 서적 미지원이 당분간 Book Club의 해자이지만, 경쟁 강도는 급격히 높아졌다.
2. **20대 SNS 독서 인증 문화 (#책스타그램 608만 게시물)** — 핵심 세그먼트(20대 독서율 74.5%)가 독서 경험을 SNS에 공유하는 습관이 대규모로 존재한다. 인증 카드 품질이 바이럴 유입의 핵심 레버다.
3. **문토 오프라인 독서 모임 규모 확인 (80만 사용자, 월 1.5만 커뮤니티)** — 온라인 독서 앱과 오프라인 모임 플랫폼이 공존하는 시장. M30 오프라인 모임 기능을 위치 기반으로 심화하면 경쟁 포지셔닝을 강화할 수 있다.
4. **밀리 'AI 독파밍' 출시 미확인 → 공백 존재** — 밀리는 "책 내용 요약·챗봇" 방향, Book Club은 "독서 준비·성찰 코치" 방향으로 AI 포지셔닝을 차별화할 기회가 열려 있다.

**Phase 14 전략**:

1. **공개 출시 & ASO** — 소프트 런치에서 공개 출시로 전환, ASO 최적화로 유기적 유입 확보.
2. **SNS 바이럴 루프** — 인증 카드 고도화로 #책스타그램 유입을 구조화된 성장 채널로 만든다.
3. **AI 독서 어시스턴트** — Fable의 "분석" vs Book Club의 "코치" 포지셔닝 차별화. 완독 전·후 AI 가이드로 독서 경험의 질을 높이면서 Pro 전환 유인을 강화한다.
4. **오프라인 모임 위치 기반 강화** — 문토와 직접 경쟁하는 위치 기반 독서 모임 탐색으로 오프라인 커뮤니티 해자를 심화한다.
5. **수익화 전환율 최적화** — M43 A/B 실험 데이터 기반으로 페이월 최적화, 연간 구독 온보딩 캠페인으로 LTV를 높인다.

## 3. M61 — 앱스토어 공개 출시 & ASO 최적화

### 3.1 목표

TestFlight(iOS) + Google Play 내부 테스트에서 공개 배포로 전환하고,
ASO(App Store Optimization) 최적화로 유기적 유입 기반을 확보한다.

### 3.2 구현 범위

**iOS 공개 출시**:
- App Store Connect에서 TestFlight → 공개 제출 전환 (Review 재심사).
- 스크린샷 5장 최종 업데이트 (온보딩·타이머·클럽·챌린지·인증카드 화면).
- 앱 설명 1차 ASO 최적화: 제목 "북클럽 — 독서 기록 & 독서 모임" / 부제목 "타이머·챌린지·독서 친구" / 키워드 100자: 독서기록,독서앱,북클럽,독서타이머,독서일기,독서챌린지,책추천,독서모임,독서습관,서재관리.

**Android 공개 출시**:
- Google Play 내부 테스트 → 오픈 테스트 → 프로덕션 트랙 순차 전환.
- Google Play 피처드 이미지(1024×500) 및 프로모션 텍스트 작성.

**인앱 리뷰 요청**:
- iOS: `in_app_review` 패키지 적용 — 타이머 세션 5회 완료 직후 트리거.
- Android: `PlayReview` API 동일 조건으로 적용.
- 하루 1회, 앱당 3회 초과 요청 방지 (`SharedPreferences`로 카운트 관리).

**버전**:
- `pubspec.yaml` → `0.1.1+2`.
- 배포 태그: `v0.1.1-m61`.

### 3.3 성공 지표

- iOS App Store 공개 게시 완료.
- Android 프로덕션 트랙 출시 완료.
- 첫 2주 이내 리뷰 10건 이상 달성 목표.

## 4. M62 — SNS 인증 카드 고도화

### 4.1 목표

M51에서 구현한 기본 SNS 공유를 #책스타그램 최적화 고도화 카드로 전환한다.
공유된 카드가 Book Club 유입 채널로 기능하도록 딥링크 + 바이럴 추적을 내장한다.

### 4.2 비즈니스 규칙

**카드 템플릿 5종**:

| 타입 | 트리거 시점 | 비율 | 주요 콘텐츠 |
|---|---|---|---|
| `book_completed` | 완독 이벤트 | 1:1 / 4:5 | 책 표지·독서 기간·총 독서 시간·별점 |
| `reading_streak` | N일 스트릭 달성 | 1:1 | 스트릭 수·아이콘·격려 문구 |
| `challenge_badge` | 배지 획득 | 1:1 / 9:16(스토리) | 배지 이미지·챌린지명·달성일 |
| `monthly_recap` | 월말 RecapCard | 4:5 | 이달 독서량·장르 파이·하이라이트 |
| `progress_checkin` | 독서 세션 종료 | 1:1 | 현재 진도 퍼센트·페이지·책 표지 |

**딥링크 포함**:
- 카드 하단에 `bookclub.app/join?ref=<referral_code>` QR 생성 (qr_flutter 패키지).
- M31 referral 코드 재사용 — 공유로 유입된 신규 가입자 추적.

**공유 후 이벤트 기록**:
- `POST /me/share-events` — `card_type`, `platform` (instagram/twitter/kakaotalk/copy), `referral_code`.

## 5. M63 — AI 독서 어시스턴트 (Claude API)

### 5.1 목표

Fable의 "AI 독서 분석(사후)" vs Book Club의 "AI 독서 코치(전후)" 포지셔닝 차별화.
독서 시작 전 준비카드와 완독 후 성찰 가이드로 독서 경험의 질을 높이고 Pro 전환 유인을 강화한다.

### 5.2 비즈니스 규칙

**기능 1 — 독서 전 준비카드** (무료, 일 5회 제한):
- 독서 시작 버튼 클릭 시 선택적 제공 ("AI 도움으로 준비할까요?").
- Claude API에 `book.title + book.author + book.description` 전달 → 생성:
  - 저자 한 줄 소개 + 이 책이 탄생한 배경.
  - 이 책의 핵심 테마 키워드 3개.
  - 읽기 전 생각해볼 질문 2개.
- M42 `curation_cards` 테이블 확장 — `source: 'ai_prep'` 타입 추가.
- 캐싱: 같은 book_id의 prep 카드는 Redis에 72h 캐시 (`ai_prep:{book_id}`).

**기능 2 — 완독 성찰 가이드** (Pro 전용):
- `BOOK_COMPLETED` 이벤트 직후 "AI 성찰 가이드 열기" CTA 노출.
- Claude API에 `book 정보 + 사용자 하이라이트 목록(최대 10개) + 독서 기간` 전달 → 생성:
  - 내가 밑줄 그은 문장들을 관통하는 핵심 인사이트 2가지.
  - 일상에 적용 가능한 실천 포인트 1가지.
  - 이 책과 연결된 다음 읽을 책 추천 2권 (네이버 책 API 연동).
- Pro 게이트: 무료 사용자는 첫 완독 1회만 체험 가능.
- Rate limit: Pro 무제한, 무료 월 1회.

**기능 3 — 클럽 토론 키워드** (Pro 클럽장 전용):
- M52 클럽 AI 코치 확장.
- 클럽 현재 독서 책 + 이번 주 범위(페이지 범위) → 토론 주제 3가지 자동 생성.
- 클럽 채팅방에 "이번 주 토론 주제" 고정 메시지로 자동 게시.

### 5.3 DB 변경

## 6. M64 — 위치 기반 오프라인 모임 강화

### 6.1 목표

M30에서 구현한 기본 `ClubEventsScreen` + RSVP를 위치 기반으로 심화한다.
문토(80만 사용자, 월 1.5만 커뮤니티)와 직접 경쟁하는 독서 모임 탐색 기능을 만든다.

### 6.2 비즈니스 규칙

**위치 기반 모임 탐색**:
- 사용자 위치(GPS 또는 수동 설정) 반경 5km 내 오픈 모임 탐색.
- 필터: 날짜 범위, 최대 인원, 장르, 온/오프 구분.
- 정렬: 거리순·날짜순·인기순.

**번개 모임** (클럽 없이 단독 모임 생성):
- 누구나 독립적인 오프라인 독서 모임을 생성 가능.
- 호스트 닉네임 + 모임 이름 + 장소 + 정원 + 읽을 책 설정.
- 카카오맵 장소 검색 API로 위치 설정.

**RSVP 강화**:
- RSVP 후 카카오톡 일정 공유 (`kakao_flutter_sdk` 캘린더 API).
- 모임 24시간 전 FCM 리마인더 자동 발송.
- 참가자 수 상한 초과 시 대기 명단(waitlist) 기능.

**모임 후 리뷰**:
- 모임 종료 다음 날 호스트에게 리뷰 FCM 발송.
- 참가자 → 모임 별점(1–5) + 한 줄 후기.
- 호스트 평점 누적 → 프로필 표시.

### 6.3 DB 변경

```sql
-- events 테이블 확장 (M30 기존 테이블)
ALTER TABLE events
    ADD COLUMN lat DOUBLE PRECISION,
    ADD COLUMN lng DOUBLE PRECISION,
    ADD COLUMN address TEXT,
    ADD COLUMN max_attendees INT,
    ADD COLUMN is_public BOOLEAN NOT NULL DEFAULT TRUE,
    ADD COLUMN club_id UUID REFERENCES clubs(id) ON DELETE SET NULL;  -- nullable (번개 모임)

CREATE INDEX idx_events_location ON events USING GIST (
    ll_to_earth(lat, lng)
) WHERE lat IS NOT NULL AND deleted_at IS NULL;

CREATE TABLE event_waitlist (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    event_id UUID NOT NULL REFERENCES events(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    queued_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE(event_id, user_id)
);

CREATE TABLE event_reviews (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    event_id UUID NOT NULL REFERENCES events(id) ON DELETE CASCADE,
    reviewer_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    rating NUMERIC(2,1) NOT NULL CHECK (rating >= 1.0 AND rating <= 5.0),
    body TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE(event_id, reviewer_id)
);
```

> `ll_to_earth` PostGIS 함수 사용. earthdistance + cube PostgreSQL 확장 활성화 필요 (`CREATE EXTENSION IF NOT EXISTS cube; CREATE EXTENSION IF NOT EXISTS earthdistance;`).

### 6.4 백엔드 API 변경

| 메서드 | 경로 | 설명 |

## 7. M65 — 수익화 전환율 최적화

### 7.1 목표

공개 출시 후 실제 수익 데이터를 기반으로 페이월 최적화, 연간 구독 온보딩 캠페인,
이탈 방지 리마인더를 실행해 MRR을 향상시킨다.

### 7.2 구현 범위

**M43 A/B 실험 결과 분석 및 적용**:
- 페이월 진입 시점 실험 (즉시 vs 3회 세션 후): winning variant 고정.
- 가격 표시 실험 (월가격 강조 vs 연간 절약액 강조): winning variant 고정.
- `experiments` 테이블 데이터 분석 후 experiment_id 종료 처리.

**얼리버드 연간 구독 캠페인**:
- 공개 출시 D+30까지: 연간 59,000원 → 53,100원 (10% 할인).
- `GET /subscriptions/promo` — 현재 활성 프로모 조회.
- `PromoOfferingRepository` — 프로모 코드 + 만료일 관리.
- 페이월 상단 "얼리버드 혜택" 배너 (카운트다운 타이머).

**신규 유저 Pro 7일 무료 체험**:
- 회원가입 후 7일간 Pro 기능 접근 허용 (RevenueCat Free Trial 오퍼링).
- 체험 D-1 FCM: "내일 Pro 혜택이 종료돼요 — 지금 구독하면 30% 할인".
- `is_in_trial BOOLEAN` 컬럼 users 테이블 추가.

**전환 퍼널 분석 (admin 확장)**:
- `GET /admin/conversion-funnel` — 페이월 노출 → 클릭 → 구독 전환율.
- `GET /admin/revenue-metrics` — MRR, ARR, ARPU, Churn Rate, LTV.
- RevenueCat Webhook 데이터 → `subscription_events` 활용.

**이탈 사용자 재참여 리마인더**:
- 구독 만료 D-7: "독서 스트릭이 곧 사라져요" 푸시.
- 구독 만료 D-3: "Pro 전용 챌린지 배지 획득이 닫혀요" 푸시.
- 구독 만료 D+1: "다시 시작하면 첫 달 20% 할인" 푸시.
- `NotificationService.schedule_subscription_reminders()` Celery 주기 태스크.

### 7.3 DB 변경

```sql
ALTER TABLE users
    ADD COLUMN trial_started_at TIMESTAMPTZ,
    ADD COLUMN trial_ends_at TIMESTAMPTZ;

CREATE TABLE subscription_promos (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    promo_code VARCHAR(32) UNIQUE NOT NULL,
    discount_pct INT NOT NULL,
    valid_from TIMESTAMPTZ NOT NULL,
    valid_until TIMESTAMPTZ NOT NULL,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```
