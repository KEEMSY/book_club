# Phase 8 — 성장 기반 구축 & 앱 완성도

## 1. 배경

Phase 7(`v0.4.0`)에서 스트릭 보호·소셜 리더보드·연중 회고·챕터 채팅방·오프라인 모임까지 완료했다.
앱 핵심 기능은 갖춰졌으나 **사용자 유입 루프**와 **수익화 기반**이 없는 상태다.

시장 분석(`docs/2026-06-07-market-analysis.md`) 핵심 시사점:
- 콘텐츠 없는 구독 WTP는 불확실 → 무료 MAU 확보 후 A/B 실험으로만 답을 얻는다.
- 바이럴 루프(친구 초대, 공유)가 초기 성장의 핵심 레버.
- 공개 클럽 발견이 신규 사용자 활성화의 핵심 진입점.

## 3. M31 — 친구 초대 & 딥링크

### 3.1 목표

사용자가 친구를 앱으로 초대할 수 있는 **개인 초대 링크**를 생성하고,
링크를 통해 앱을 설치·가입하면 **초대자와 피초대자 모두에게 보상**을 지급한다.
딥링크를 통해 앱 미설치 사용자는 스토어로, 설치 사용자는 앱 내 직접 진입이 가능하다.

### 3.2 비즈니스 규칙

- **초대 코드 생성**: 사용자당 고유 6자 alphanumeric 코드. 만료 없음.
- **보상**: 피초대자가 첫 독서 세션(≥1분)을 완료 시 초대자에게 스트릭 쉴드 1개 지급.
- **중복 방지**: 이미 가입된 이메일/소셜 계정은 초대 완료 처리 안 함.
- **통계**: 초대한 수 / 가입 완료 수를 프로필 화면에 표시.

### 3.3 DB 변경

```sql
-- users 테이블에 referral_code 추가
ALTER TABLE users ADD COLUMN referral_code VARCHAR(8) UNIQUE;

-- 초대 추적 테이블
CREATE TABLE referrals (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    referrer_id UUID NOT NULL REFERENCES users(id),
    referee_id UUID REFERENCES users(id),      -- 가입 완료 시 채워짐
    code VARCHAR(8) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    completed_at TIMESTAMPTZ                   -- 첫 세션 완료 시
);
CREATE INDEX idx_referrals_referrer ON referrals(referrer_id);
CREATE INDEX idx_referrals_code ON referrals(code);
```

### 3.4 백엔드 API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/me/referral` | 내 초대 코드 + 통계 반환 |
| POST | `/auth/register` | `referral_code` 파라미터 추가 |
| — | (이벤트) | 세션 완료 시 referral 완료 처리 & 쉴드 지급 |

### 3.5 모바일 변경

- 프로필 탭 하단에 "친구 초대" 섹션: 초대 링크 복사, 카카오톡 공유, QR 코드.
- 딥링크 스킴: `bookclub://invite/{code}` — go_router `onDeeplink` 처리.
- 초대 통계 카드 (초대함 N명 / 가입 완료 M명).

## 4. M32 — 공개 클럽 발견

### 4.1 목표

현재 클럽은 초대 코드로만 참여 가능하다. **공개 클럽** 개념을 도입해 누구나 참여 가능한
클럽을 만들고, 탐색·검색·추천으로 신규 사용자가 커뮤니티에 빠르게 진입할 수 있게 한다.

### 4.2 비즈니스 규칙

- 클럽 생성 시 `is_public: bool` 설정 가능 (기본값: false — 기존 동작 유지).
- 공개 클럽은 초대 코드 없이 직접 가입 가능. `max_members` 제한은 동일 적용.
- 탐색 탭에 "클럽 찾기" 섹션 추가: 인기 순 / 최신 순 / 지금 읽는 책 기준.
- 검색: 클럽 이름 / 현재 읽는 책 제목으로 검색.

### 4.3 DB 변경

```sql
ALTER TABLE reading_clubs ADD COLUMN is_public BOOLEAN NOT NULL DEFAULT false;
CREATE INDEX idx_clubs_public ON reading_clubs(is_public) WHERE is_public = true;
```

### 4.4 백엔드 API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/clubs/public` | 공개 클럽 목록 (페이지네이션, 정렬) |
| GET | `/clubs/public/search?q=` | 이름·책 제목 검색 |
| POST | `/clubs/{id}/join-public` | 초대 코드 없이 공개 클럽 가입 |

## 5. M33 — 개인화 독서 리마인더 & 알림 센터

### 5.1 목표

사용자가 독서 리마인더 시간을 직접 설정하고, 앱 내 알림 센터에서
모든 알림 이력을 확인할 수 있게 한다. 스마트 리마인더(연속 미접속 감지)도 도입한다.

### 5.2 비즈니스 규칙

- **리마인더 설정**: 요일·시간대 선택. 최대 7개(요일별). 기본값: 매일 저녁 9시.
- **스마트 푸시**: 48시간 미접속 + 스트릭 > 3일인 사용자에게 "스트릭이 끊길 위험!" 알림.
- **알림 센터**: 최근 90일 알림 이력 조회. 읽음/안읽음 상태. 배지 카운트 동기화.

### 5.3 DB 변경

```sql
CREATE TABLE reading_reminders (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    days_of_week INTEGER[] NOT NULL,   -- 0=월 ~ 6=일
    remind_at TIME NOT NULL,
    is_active BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## 6. M34 — Pro 구독 인프라

### 6.1 목표

수익화 A/B 실험을 위한 **구독 인프라**를 구축한다. Phase 8에서는 RevenueCat SDK 연동과
서버 검증까지만 구현하고, 실제 유료 기능 잠금은 최소화하여 전환 데이터를 먼저 측정한다.

### 6.2 Pro 혜택 (초기안)

- 쉴드 최대 보유량 3개 → **5개**
- 클럽 최대 개설 수 1개 → **3개**
- 고급 독서 통계 (월별 페이지 수, 장르 분포)
- 광고 없는 경험 (향후 광고 도입 대비)

### 6.3 구현 범위

- RevenueCat SDK (iOS + Android) 연동
- `users.is_pro: bool`, `users.pro_expires_at: timestamptz` 컬럼
- `POST /me/subscription/verify` — 영수증 검증 엔드포인트
- 모바일: Paywall 화면, Pro 배지 표시
