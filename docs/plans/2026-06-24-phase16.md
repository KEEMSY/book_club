# Phase 16 — SDK 완성 & 글로벌 확장 준비 (M71~M75)

## 배경

Phase 15에서 커뮤니티 2단계(M68), 검색·발견 고도화(M69), B2B 수익화(M70)를 완료했다.
Phase 16은 두 가지 축에 집중한다:
1. **스텁 완성**: M68 Agora RTC 스텁 → 실 SDK, M64/M68 카카오맵 플레이스홀더 → 실 SDK
2. **글로벌 확장 준비**: 국제화(i18n), Flutter Web MVP, 멀티 리전 인프라, E2E 품질 게이트

## M71 — 실 외부 SDK 연동 완성

**목표**: 스텁/플레이스홀더로 남아있는 영상 통화(Agora)와 지도(카카오맵)를 실 SDK로 교체한다.

### M71-1: Agora RTC 실 연동

**백엔드**:
- `backend/app/domains/video/adapters/agora_adapter.py` 실 구현
  - `AgoraStubAdapter` → `AgoraRealAdapter`
  - Agora App ID + App Certificate (Fly.io secret: `AGORA_APP_ID`, `AGORA_APP_CERTIFICATE`)
  - `generate_token(channel, uid, expiry_secs)` — RTC Token Builder (Python SDK)
  - `POST /video-sessions` 응답에 `agora_token` 포함
- `backend/app/domains/video/ports.py` `VideoSessionPort.generate_token()` 추가

**모바일**:
- `pubspec.yaml`: `agora_rtc_engine: ^6.3.2` 추가
- `mobile/lib/features/video/` 신규:
  - `presentation/video_session_screen.dart` — `AgoraVideoView` 실 렌더링
  - `domain/video_session_state.dart` (freezed)
  - `application/video_session_controller.dart` (riverpod codegen)
- `VideoSessionScreen`: 호스트/참여자 레이아웃, 마이크·카메라 토글, 종료 버튼

### M71-2: 카카오맵 SDK 실 연동

**모바일**:
- `pubspec.yaml`: `kakao_map_plugin: ^2.1.1` 추가
- `mobile/lib/features/event/presentation/nearby_events_screen.dart` 지도뷰 교체
  - `KakaoMap` 위젯 + 마커 클러스터링
  - 내 위치 중심, 반경 5km 이벤트 마커 표시
  - 마커 탭 → `EventDetailScreen` 이동
- `AndroidManifest.xml` / `Info.plist`: 카카오 API 키 메타데이터 추가 (`.env`에서 주입)

**DB/백엔드 변경 없음** (M64 earthdistance 인덱스 그대로 사용)

## M72 — 국제화(i18n) 인프라

**목표**: 앱을 한국어·영어·일본어 3개 언어로 지원할 기반을 구축한다.

### 모바일

- `pubspec.yaml`:
  - `flutter_localizations` (SDK 번들)
  - `intl: ^0.19.0`
  - `flutter_intl` (VS Code 플러그인용, build_runner 통합)
- `l10n.yaml` 생성 (ARB 경로 지정)
- `lib/l10n/` 디렉터리:
  - `app_ko.arb` — 한국어 (기준)
  - `app_en.arb` — 영어 (1차 번역)
  - `app_ja.arb` — 일본어 (1차 번역, 빈 문자열 허용)
- `MaterialApp.localizationsDelegates`, `supportedLocales` 설정
- 주요 UI 문자열 ARB 교체 (온보딩, 홈 탭, 타이머, 클럽 카드)

### 백엔드

- `Accept-Language` 미들웨어 — `ko`/`en`/`ja` 파싱, `request.state.lang` 설정
- 오류 응답 메시지 i18n (`shared/i18n.py` 딕셔너리)
- 책 검색 API — `lang` 쿼리 파라미터 → 네이버(ko) / Open Library(en/ja) 분기

## M73 — Flutter Web MVP

**목표**: 동일 코드베이스에서 웹 빌드를 제공하고 PWA로 배포한다.

### 빌드 파이프라인

- `mobile/web/index.html` — PWA manifest, theme-color, splash
- `mobile/web/manifest.json` — name, icons, display: standalone
- `mobile/web/service_worker.js` — 오프라인 캐시 (workbox-precaching 기반)
- `flutter build web --release --web-renderer canvaskit`

### 반응형 레이아웃

- `lib/core/layout/adaptive_layout.dart` — `LayoutBuilder` + breakpoint (mobile <600, tablet <1024, desktop ≥1024)
- `DashboardScreen`, `LibraryScreen`, `ClubDetailScreen` 반응형 Sidebar 레이아웃 적용
- 웹 전용 NavigationRail (사이드바) vs. 모바일 BottomNavigationBar

### 배포

- `mobile/Dockerfile.web` (nginx:alpine 기반)
- `.github/workflows/deploy-web.yml`:
  - `flutter build web` → `ghcr.io` 이미지 빌드 → Fly.io `book-club-web` 앱 배포
  - 스테이징 URL: `https://book-club-web.fly.dev`

### 기능 제한 (웹 MVP 제외)

- FCM 푸시 알림 (웹 푸시 Phase 17)
- Agora RTC (WebRTC 래퍼 Phase 17)
- Apple Sign In (웹 미지원 → 카카오 전용)
- RevenueCat IAP (웹 결제 Phase 17)

## M74 — 인프라 고도화

**목표**: 서비스 지역 확대(일본·동남아)에 대비한 멀티 리전 배포와 DB 성능 강화를 완료한다.

### Fly.io 멀티 리전

- `fly.toml`:
  - 기존: `nrt` (Tokyo) primary
  - 추가: `sin` (Singapore) replica
- `PRIMARY_REGION=nrt` 환경 변수 — 쓰기 요청은 primary로 리다이렉트
- `fly volumes create pg_data_sin --region sin` — Postgres replica volume

### PgBouncer 커넥션 풀링

- `docker-compose.yml`에 `pgbouncer` 서비스 추가 (로컬 개발용)
- `backend/app/core/database.py` — `pool_size=5, max_overflow=10` → PgBouncer 통해 연결
- `DATABASE_URL`을 PgBouncer 엔드포인트로 교체 (Fly.io secret 업데이트)

### CDN 이미지 최적화

- Cloudflare R2 앞에 Cloudflare Images (자동 WebP 변환, 리사이징)
- `backend/app/shared/storage.py` `upload_image()` — `cf-images` 엔드포인트로 교체
- 모바일 `CachedNetworkImage` URL에 `?format=webp&w=400` 쿼리 추가

### 모니터링 강화

- Grafana 대시보드 `book-club-phase16.json`:
  - 지역별 응답 시간 분포
  - DB 커넥션 풀 사용률
  - R2/CDN 캐시 히트율
