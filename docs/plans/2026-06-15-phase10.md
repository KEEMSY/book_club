# Phase 10 — 차별화 완성 & 시장 출시

## 1. 배경

Phase 9(`v0.6.0`)에서 수익화 인프라·피드 고도화·통합 검색·관리자 대시보드까지 완성했다.
2차 시장 분석(`docs/2026-06-07-market-analysis.md` v1.1.0, 2026-06-14)이 Phase 10 방향을 재정의했다.

**핵심 발견 3가지**:

1. **NRC 성장 엔진 확인** — 시간 제한 챌린지 + 희소성 전용 배지(기간 한정·재획득 불가)가 유지율의 핵심. Book Club은 챌린지 인프라는 있으나 배지 희소성 레이어가 없다.
2. **밀리 AI 피벗** — 밀리의서재가 AI 기반 독서 경험을 공식 전략으로 선언. ML 추천 차별화가 경쟁 우선순위로 격상.
3. **WTP 불확실** — 한국 시장 콘텐츠 없는 구독 WTP는 실증 데이터 없음. A/B 실험만이 답.

## 3. M41 — 챌린지 배지 희소성 강화

### 3.1 목표

기존 챌린지(M9/M12)에 **기간 한정·재획득 불가** 배지 레이어를 추가한다.
NRC가 검증한 희소성 원리 — 배지를 "영원히 못 받을 수도 있다"는 긴장감이 참여 동기를 강화한다.

### 3.2 비즈니스 규칙

- 챌린지에 `is_limited: bool`, `ends_at: timestamptz`, `badge_id_exclusive: UUID | None` 필드 추가.
- `is_limited=True`인 챌린지의 전용 배지는 해당 챌린지를 기간 내 완료한 사용자만 획득 가능.
- 기간 종료 후 배지 획득 불가 (어드민도 수동 부여 불가 — 희소성 보장).
- 챌린지 목록 UI에 **"D-N 종료"** 카운트다운 표시.
- 내 배지 화면에 "기간 한정" 뱃지 + 획득 날짜 표시.

### 3.3 DB 변경

```sql
ALTER TABLE challenges ADD COLUMN is_limited BOOLEAN NOT NULL DEFAULT false;
ALTER TABLE challenges ADD COLUMN ends_at TIMESTAMPTZ;
ALTER TABLE challenges ADD COLUMN badge_id_exclusive UUID REFERENCES badges(id);
```

### 3.4 백엔드 API 변경

- `GET /challenges` 응답에 `is_limited`, `ends_at`, `days_remaining` 필드 추가.
- `POST /admin/challenges` 생성 시 `is_limited`, `ends_at`, `badge_id_exclusive` 지원.
- 기간 만료된 챌린지에 진행 완료해도 배지 미부여 (서비스 레이어에서 `ends_at` 검증).

### 3.5 모바일 변경

- 챌린지 카드에 기간 한정 배너 + D-N 카운트다운 칩.
- 내 배지 화면 — 희소 배지 구분 아이콘(✦).

## 4. M42 — 독서 큐레이션 카드 MVP

### 4.1 목표

NRC 오디오 코칭의 Book Club 대응. 오디오 제작은 비용이 크므로
**텍스트 큐레이션 카드** (작가 소개·독서 가이드·책 배경 이야기)로 MVP를 만든다.

타이머 시작 전 "오늘 읽을 책에 대한 3줄 가이드"를 노출 → 독서 준비 의식 형성.

### 4.2 비즈니스 규칙

- 큐레이션 카드는 책(`book_id`) 단위로 연결. 1권 = 최대 5장 카드.
- 카드 타입: `intro`(작가 소개), `guide`(독서 가이드), `context`(역사적 배경), `quote`(대표 문장).
- 어드민이 직접 입력 또는 Claude API로 초안 생성 후 편집.
- 타이머 화면 시작 시 해당 책의 첫 번째 카드 자동 노출 (닫기 가능).

### 4.3 DB 변경

```sql
CREATE TABLE curation_cards (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    book_id UUID NOT NULL REFERENCES books(id) ON DELETE CASCADE,
    card_type VARCHAR(16) NOT NULL,  -- intro|guide|context|quote
    title VARCHAR(100) NOT NULL,
    body TEXT NOT NULL,
    order_index INT NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_curation_cards_book ON curation_cards(book_id, order_index);
```

### 4.4 API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/books/{id}/curation-cards` | 책 큐레이션 카드 목록 |
| POST | `/admin/books/{id}/curation-cards` | 어드민 카드 생성 |
| DELETE | `/admin/curation-cards/{id}` | 어드민 카드 삭제 |

### 4.5 모바일

- `TimerScreen` 시작 시 해당 `userBookId`의 책 큐레이션 카드 1장 팝업 (BottomSheet).
- "독서 시작" 버튼으로 닫기.

## 5. M43 — Pro 수익화 A/B 실험 인프라

### 5.1 목표

한국 시장 WTP를 실증할 A/B 실험 인프라 구축.
RevenueCat 구현(M36)은 완료 — 이제 **어떤 페이월 메시지/가격/진입점**이 전환율을 높이는지 실험한다.

### 5.2 구현 범위

- `user_experiments` 테이블 — 사용자별 실험 배정 (`experiment_key`, `variant`).
- `GET /me/experiments` — 현재 사용자의 활성 실험 배정 목록.
- **실험 1: 페이월 진입 시점** — A: 통계 탭 클릭 시, B: 클럽 3개 초과 시.
- **실험 2: 가격 표시** — A: 6,900원/월, B: 69,000원/년(월 5,750원).
- 관리자 대시보드에 실험별 노출수·전환수 통계 추가.

## 6. M44 — ML 추천 고도화

### 6.1 목표

밀리의서재 AI 피벗에 대응. M21의 협업 필터링 기반 추천을 강화한다.

### 6.2 구현 범위

- **사용자 독서 임베딩**: 완독 책의 장르·저자·키워드 벡터 합산 → 사용자 취향 프로파일.
- `GET /me/recommendations?strategy=similar_readers|taste_match` — 전략 파라미터 추가.
- **콜드스타트 해결**: 신규 사용자는 온보딩에서 선택한 장르·관심사 기반 초기 추천.
- 모바일: 탐색 탭 "AI 추천" 섹션에 추천 근거 한 줄 표시 ("비슷한 독서 패턴의 사용자가 읽은 책").
