# Phase 9 — 수익화 완성 & 데이터 기반 성장

## 1. 배경

Phase 8(`v0.5.0`)에서 성장 기반(친구 초대·공개 클럽·리마인더)과 수익화 인프라(Pro 구독 stub)를 완성했다.

## 3. M36 — RevenueCat 실 결제 연동

### 3.1 목표
Phase 8의 영수증 검증 stub을 RevenueCat 서버 사이드 검증으로 교체한다.
RevenueCat REST API v1로 iOS/Android 영수증을 검증하고, 구독 상태를 실시간 동기화한다.

### 3.2 비즈니스 규칙
- **iOS**: StoreKit 2 구매 완료 → receipt_data(JWS) → RevenueCat POST /receipts
- **Android**: Play Billing Library → purchase_token → RevenueCat POST /receipts
- **Webhook**: RevenueCat CUSTOMER_PURCHASE / CANCELLATION 이벤트 → POST /webhooks/revenuecat
- **구독 상태 동기화**: webhook 수신 시 users.is_pro + pro_expires_at 업데이트

### 3.3 구현
- `backend/app/domains/subscription/service.py`의 `verify_and_activate` stub 교체
- `backend/app/domains/subscription/adapters/revenuecat_adapter.py` 신규 (External Adapter)
- `POST /webhooks/revenuecat` 엔드포인트 추가
- RevenueCat API Key는 `.env` → `REVENUECAT_API_KEY`

## 4. M37 — 독서 활동 피드 고도화

### 4.1 목표
현재 피드는 기본 독서 기록만 보여준다. 챕터 완료, 스트릭 달성, 책 완독, 클럽 입장 등
다양한 활동 타입을 피드에 통합해 소셜 인게이지먼트를 높인다.

### 4.2 피드 활동 타입 추가
- `CHAPTER_MILESTONE`: N장 완료
- `STREAK_MILESTONE`: N일 스트릭 달성
- `BOOK_COMPLETED`: 책 완독 + 한줄 리뷰
- `CLUB_JOINED`: 공개 클럽 참여
- `SHIELD_USED`: 쉴드 사용으로 스트릭 유지

### 4.3 구현
- `feed_events.event_type` ENUM 확장
- 각 이벤트 발생 시점(service.py)에서 피드 이벤트 기록
- 모바일: 피드 카드 타입별 UI 컴포넌트 추가

## 5. M38 — 검색 & 발견 강화

### 5.1 목표
현재 책 검색은 외부 API(네이버/카카오)에만 의존한다.
내부 카탈로그 검색 + 사용자/클럽 통합 검색을 추가한다.

### 5.2 구현 범위
- `GET /search?q=&type=book|user|club` — 통합 검색 엔드포인트
- 내부 카탈로그(books 테이블) full-text search (PostgreSQL `tsvector`)
- 사용자 닉네임 검색
- 모바일: SearchScreen 통합 결과 탭 UI

## 6. M39 — 관리자 대시보드 & 콘텐츠 운영

### 6.1 목표
챌린지·배지 시드, 사용자 신고 처리, MAU/DAU 지표를 보는 최소 관리 UI.

### 6.2 구현 범위
- `GET /admin/stats` — MAU, DAU, 신규 가입, Pro 전환율
- `GET/PATCH /admin/users/{id}` — 사용자 정지/해제
- `GET/POST /admin/reported-content` — 신고 내용 목록 + 처리
