# Phase 15 — 성장 최적화 & 커뮤니티 심화

## 1. 배경

Phase 14(`v1.1.0`)에서 공개 출시와 그로스 엔진(ASO·SNS 바이럴·AI 어시스턴트·위치 기반 모임·수익화 최적화)을 완료했다.
Phase 15는 실제 공개 출시 후 데이터를 기반으로 제품을 안정화하고,
사용자 잔존율·수익 두 축을 동시에 높이는 심화 단계다.

**Phase 15 전략**:

1. **안정화 우선** — 공개 출시 직후 Sentry 에러·UX 피드백·미완 배선(TrialBanner·curation 버그)을 먼저 정리한다.
2. **AI 개인화 심화** — Claude API 기반 큐레이션 피드백 루프와 오디오 독서 코치 MVP로 AI 차별화를 강화한다.
3. **커뮤니티 오프라인 완성** — M64 모임 기능에 지도뷰와 영상 통화를 더해 문토와 직접 경쟁한다.
4. **발견 고도화** — 맞춤 책 큐레이션 채널로 신규 유입·잔존율을 동시에 잡는다.
5. **B2B 탐색** — 기업 독서 클럽 팀 플랜으로 수익 다각화의 첫 발을 뗀다.

## 3. M66 — 공개 출시 후 안정화 스프린트

### 3.1 목표

공개 출시 직후 누적된 버그, 미완 배선, UX 마찰을 제거해 잔존율 기반을 다진다.

### 3.2 구현 범위

**미완 배선 완료**:
- `TrialBanner` 위젯(m65 생성)을 홈 화면(`DashboardScreen` 또는 `AppShell` 상단)에 연결.
  `trialStatusProvider` 구독 → `isInTrial && daysRemaining > 0` 조건 시 배너 표시.
- `firstCurationCardProvider(bookId: widget.userBookId)` 버그 수정:
  큐레이션 카드 API가 catalog `book_id` 기준임을 확인하고, `userBookId`(UserBook UUID)를
  올바른 `book_id`(catalog UUID)로 교체. TimerScreen에 이미 `widget.bookId`가 있으므로
  `firstCurationCardProvider(bookId: widget.bookId)` 로 변경 (bookId 없을 때 pre-fetch 스킵).

**Sentry P1 버그 수정**:
- 공개 출시 후 Sentry에 수집된 상위 5개 에러 트리아지 및 수정.
- Crash-free sessions 99.5% 이상 유지 목표.

**UX 개선**:
- `NearbyEventsScreen` 빈 상태(모임 없음) UI 개선 — 로딩 실패와 결과 없음 명확히 구분.
- `ClubDetailScreen` AI 토론 주제 오류 시 snackbar 메시지 한국어 통일.
- `PaywallScreen` 얼리버드 카운트다운 타이머 — 만료 후 UI 처리(배너 자동 숨김).

**성능**:
- `NearbyEventsScreen` 초기 로드 시 서울시청 기본 좌표 → 디바이스 위치 API 사용 여부 사용자 권한 요청 플로우 추가 (`geolocator` 패키지, pubspec.yaml 추가 필요).

### 3.3 DB 변경

없음 (마이그레이션 불필요).

### 3.4 성공 지표

- Crash-free sessions ≥ 99.5%.
- TrialBanner 홈 노출 → 구독 전환율 측정 시작.
- 큐레이션 카드 노출률 개선 (bookId 불일치 수정으로 404 감소).

## 4. M67 — AI 개인화 심화

### 4.1 목표

Phase 14 AI 어시스턴트(M63)의 반응 데이터를 피드백 루프에 연결하고,
오디오 독서 코치 MVP로 AI 차별화를 한 단계 높인다.

### 4.2 구현 범위

**큐레이션 카드 피드백 루프**:
- `POST /me/curation-cards/{id}/feedback` — `{action: "helpful" | "skip" | "dismiss"}` 기록.
- `curation_card_feedback` 테이블 (id, user_id, card_id, action, created_at).
- 피드백 기반 카드 순위 조정: 3회 이상 skip된 카드 유형은 해당 유저에게 노출 빈도 감소.
- 모바일: 큐레이션 카드 시트 하단에 "도움이 됐어요 / 건너뛰기" 버튼 추가.

**AI 준비카드 개인화**:
- `GET /books/{id}/ai-prep-card` 응답에 `style` 파라미터 추가: `"motivational" | "analytical" | "reflective"`.
- 사용자 선호 스타일 저장 (`user_ai_preferences` 테이블).
- 첫 사용 시 스타일 선택 온보딩 스텝 추가.

**오디오 독서 코치 MVP**:
- `POST /books/{id}/ai-audio-intro` — Claude API로 책 소개 스크립트(200자) 생성.
- Flutter TTS(`flutter_tts` 패키지)로 앱 내 재생. (외부 TTS API 미사용)
- 타이머 화면 "읽기 전 AI 준비" 버튼 옆 "듣기" 아이콘 버튼으로 진입.
- Pro 게이트 (무료 유저: 1회/일 제한).

### 4.3 DB 변경

```sql
CREATE TABLE curation_card_feedback (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    card_id UUID NOT NULL REFERENCES curation_cards(id) ON DELETE CASCADE,
    action VARCHAR(16) NOT NULL CHECK (action IN ('helpful', 'skip', 'dismiss')),
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE(user_id, card_id)
);

CREATE TABLE user_ai_preferences (
    user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    card_style VARCHAR(32) NOT NULL DEFAULT 'motivational',
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

### 4.4 성공 지표

- 큐레이션 카드 "helpful" 비율 ≥ 40%.
- 오디오 코치 일간 재생 수 추적 시작.
- AI 준비카드 Pro 전환 기여율 측정.

## 5. M68 — 커뮤니티 2단계

### 5.1 목표

M64 오프라인 모임을 지도뷰로 완성하고, 독서 클럽 영상 통화를 도입해
문토 대비 온/오프라인 통합 경험을 제공한다.

### 5.2 구현 범위

**오프라인 모임 지도뷰**:
- `NearbyEventsScreen`에 리스트뷰 ↔ 지도뷰 토글 추가.
- `kakao_map_sdk` (카카오 맵 Flutter 플러그인) 도입.
- 지도 마커 탭 → 이벤트 미리보기 바텀시트.
- `EventDetailScreen` 추가: RSVP 버튼, 대기 명단 현황, 리뷰 목록.

**독서 클럽 영상 통화 MVP**:
- `agora_rtc_engine` 패키지 기반 1:N 영상 통화 (클럽 최대 10명).
- `POST /clubs/{id}/video-sessions` — 세션 생성, Agora 토큰 발급.
- `ClubDetailScreen` → "화상 독서 모임 시작" 버튼 (Pro 클럽 오너 전용).
- `VideoSessionScreen`: 카메라·마이크 토글, 참가자 그리드, 나가기.
- 백엔드: `video_sessions` 테이블 (id, club_id, host_id, agora_channel, started_at, ended_at).

### 5.3 DB 변경

```sql
CREATE TABLE video_sessions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    club_id UUID NOT NULL REFERENCES clubs(id) ON DELETE CASCADE,
    host_id UUID NOT NULL REFERENCES users(id),
    agora_channel VARCHAR(64) NOT NULL,
    started_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    ended_at TIMESTAMPTZ,
    max_participants INT NOT NULL DEFAULT 10
);
```

### 5.4 성공 지표

- 영상 통화 첫 달 세션 수 ≥ 100회.
- `EventDetailScreen` RSVP 전환율.

## 6. M69 — 발견 고도화

### 6.1 목표

"당신을 위한 책" 맞춤 큐레이션 채널을 도입해 앱 재방문과 신규 도서 발견을 높인다.
활성 사용자 1만 조건이 충족되면 딥러닝 추천으로 업그레이드한다.

### 6.2 구현 범위

**맞춤 큐레이션 채널**:
- `GET /me/book-recommendations?channel=taste_match|trending|club_picks|ai_picks` — 채널별 10권.
- `DiscoveryScreen`에 수평 스크롤 채널 섹션 추가 (탭 아래, 검색 위).
- `ai_picks` 채널: Claude API로 사용자 독서 이력 분석 후 3권 추천 + 한 줄 이유.
- `club_picks`: 내가 속한 클럽 멤버들이 최근 완독한 책 TOP5.

**딥러닝 추천 (조건부)**:
- MAU 1만 달성 확인 시 활성화: `user_taste_profiles` 기반 ALS(교대 최소 제곱) 협업 필터링.
- 미달 시: 기존 규칙 기반 추천 유지 + 이 항목 Phase 16으로 재보류.

**검색 자동완성**:
- `GET /search/autocomplete?q=` — 책 제목·저자 자동완성 (PostgreSQL `pg_trgm`).
- 모바일: `UnifiedSearchScreen` 검색 입력 시 드롭다운 자동완성.

### 6.3 DB 변경

```sql
-- pg_trgm for autocomplete
CREATE EXTENSION IF NOT EXISTS pg_trgm;
CREATE INDEX idx_books_title_trgm ON books USING GIN (title gin_trgm_ops);
CREATE INDEX idx_books_author_trgm ON books USING GIN (author gin_trgm_ops);
```

### 6.4 성공 지표

- 맞춤 채널 클릭률(CTR) ≥ 15%.
- 채널 경유 서재 추가율.
- 검색 자동완성 사용률.

## 7. M70 — 수익화 2단계

### 7.1 목표

개인 Pro 구독 이상의 수익원으로 기업 독서 클럽(B2B) 팀 플랜을 탐색하고,
MRR 증가율을 20% 이상 끌어올린다.

### 7.2 구현 범위

**B2B 팀 플랜 MVP**:
- `team_subscriptions` 테이블: team_id, team_name, admin_user_id, seat_count, plan_type.
- `POST /teams` — 팀 생성 (연간 계약 99,000원/월·10석).
- `POST /teams/{id}/members` — 멤버 초대 (이메일 기반).
- 팀 멤버는 Pro 기능 자동 활성화 (`is_pro = true` 기간 연동).
- 관리자 화면: `TeamAdminScreen` — 멤버 목록·좌석 현황.

**MRR 대시보드 강화**:
- `GET /admin/revenue-metrics` 확장: 팀 플랜 MRR 분리, 월별 추이 그래프 데이터.
- 관리자 웹 대시보드는 Flutter 앱 내 Admin 탭으로 제공 (슈퍼유저 게이트).

**구독 만료 재참여 캠페인**:
- M65 `send_expiry_reminders` 확장: 만료 D+7 "다시 시작" 할인 쿠폰 FCM.
- `discount_coupons` 테이블 (code, discount_pct, valid_days, used_by).

### 7.3 DB 변경

```sql
CREATE TABLE team_subscriptions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    team_name VARCHAR(128) NOT NULL,
    admin_user_id UUID NOT NULL REFERENCES users(id),
    seat_count INT NOT NULL DEFAULT 10,
    plan_type VARCHAR(32) NOT NULL DEFAULT 'annual_team',
    valid_from TIMESTAMPTZ NOT NULL,
    valid_until TIMESTAMPTZ NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE team_members (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    team_id UUID NOT NULL REFERENCES team_subscriptions(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    joined_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE(team_id, user_id)
);

CREATE TABLE discount_coupons (
    code VARCHAR(32) PRIMARY KEY,
    discount_pct INT NOT NULL,
    valid_days INT NOT NULL DEFAULT 30,
    used_by UUID REFERENCES users(id),
    used_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

### 7.4 성공 지표

- 팀 플랜 첫 계약 1건 이상.
- MRR 전월 대비 +20%.
- 쿠폰 재참여율 ≥ 10%.
