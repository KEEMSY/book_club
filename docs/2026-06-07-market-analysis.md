## 1. 시장 환경

### 1.1 한국 독서 시장 (검증된 수치)

| 지표 | 수치 | 출처 |
|---|---|---|
| 성인 종합 독서율 (2023) | 43.0% (2021 대비 -4.5%p) | 문화체육관광부 2023 국민독서실태조사 |
| 종이책 독서율 | 32.3% (하락세) | 동일 |
| 전자책 독서율 | 19.4% (2013년 13.9% → 지속 증가) | 동일 |
| 밀리의서재 2024 영업이익 | 110억 원 (+5.7% YoY) | KPA 출판시장 통계보고서 |
| 밀리의서재 2022 매출 | 458억 원 (+59% YoY), 2022년 흑자전환 | 한국경제 |

**시사점**: 종이책 독서 인구는 감소하지만 전자책 독서율은 2013년 이후 꾸준히 증가 중이다. 밀리의서재의 흑자전환은 한국 시장에서 독서 구독 모델의 수익성이 검증된 사례다.

> **주의**: 시장 규모 수치($1.42B, CAGR 13.8% 등 리서치 리포트 인용값)는 검증 실패(0-3 반박). TAM 추정에 사용 불가. 밀리의서재 단가(월 9,900원), 구독자당 이용량 등 세부 데이터도 반박됨.

### 1.2 글로벌 소셜 독서 시장 (검증된 수치)

| 플랫폼 | 지표 | 수치 |
|---|---|---|
| StoryGraph | 회원 수 (2026.01) | 500만 명 돌파 (9개월간 +25%) |
| Fable (Everand 인수 후) | 커뮤니티 멤버 | 500만 명, 200K 북클럽 |
| Fable + Everand 구독 번들 | 가격 | $11.99/월 (Standard) |

"트래킹 + 소셜 커뮤니티" 결합 모델이 글로벌 주류로 부상했으며, 이 포맷의 한국 네이티브 앱은 현재 존재하지 않는다.

## 2. 경쟁 지형

### 2.1 국내 경쟁자

| 앱 | 포지션 | Book Club과 겹치는 영역 | 실질 경쟁 여부 |
|---|---|---|---|
| 밀리의서재 | 무제한 콘텐츠 구독 | 독서 기록, 커뮤니티 | 간접 — 콘텐츠 제공이 핵심 가치 |
| 리디북스 | 웹소설/웹툰 중심 플랫폼 | 독서 로그 | 없음 — 트래킹·소셜 미지원 |
| **국내 직접 경쟁자** | **없음** | — | **핵심 기회** |

### 2.2 글로벌 경쟁자

| 앱 | 핵심 기능 | Book Club과의 차이 |
|---|---|---|
| Bookly | 타이머 트래킹 (메커니즘 동일) | 인앱 소셜 없음, 영문 전용, 한국 서적 미지원 |
| StoryGraph | 독서 통계 + 무드/속도 트래킹 | 실시간 채팅 없음, 한국어 미지원 |
| Fable (Everand) | 그룹 북클럽 + 구독 번들 | 콘텐츠 플랫폼 의존, 한국어 미지원 |
| Goodreads | 책 DB + 소셜 | Amazon 백래시, UX 노후화, 한국어 약함 |

### 2.3 차별점 요약

Book Club은 **Bookly(타이머)와 Fable(그룹 소셜)의 기능을 한국어로 통합한 유일한 앱**이다. 네이버 책 API 기반 국내 서적 커버리지는 글로벌 경쟁자가 단기간에 따라오기 어려운 구조적 해자다.

## 4. 수익화 모델 벤치마크

### 4.1 검증된 모델 — Fable Plus

Fable Plus(프리미엄 티어)는 "고급 통계·인사이트, 개인화 목표, 광고 없는 경험, 보너스 배지"를 유료 잠금으로 배치하며 Everand 구독 번들에 포함되어 있다.

### 4.2 Book Club 적용 구조 (제안)

```
무료 티어
  └── 기본 타이머 + 잔디 + 책 피드 열람 + 그룹 가입 (최대 N개)

프리미엄 티어 (월정액)
  └── 심층 독서 통계 (M21 구현 완료 ← 핵심 자산)
  └── ML 추천 우선 접근 (M21)
  └── 개인화 챌린지 목표 설정
  └── 연중 독서 회고 카드 (월별·기념일)
  └── 광고 없는 경험
  └── 보너스 배지
```

M21에서 구현된 독서 통계 화면이 이미 수익화 경로의 핵심 자산으로 기능할 수 있다.

### 4.3 미해결 질문

**콘텐츠 없이 경험·커뮤니티만으로 한국 시장에서 유료 전환을 만들 수 있는가?**

밀리의서재·리디북스는 무제한 콘텐츠 제공이 구독의 핵심 가치였다. Book Club은 콘텐츠 제공 없이 "읽기 경험 + 커뮤니티"만으로 WTP를 만들어야 한다. 시장 데이터가 존재하지 않으므로 초기 무료 → 유료 전환 퍼널 A/B 실험으로만 답을 얻을 수 있다.

## 5. 개선 우선순위

### 5.1 즉시 적용 가능 (현재 기능 강화)

**① 스트릭 보호 메커니즘** (Duolingo/NRC 검증 패턴)
- 하루 놓쳤을 때 "스트릭 쉴드" — 이탈 방지의 핵심 레버
- Duolingo는 스트릭 보호를 유료 전환의 트리거로 활용

**② 소셜 리더보드 강화**
- 팔로잉 기준 주간 독서 시간 리더보드 (NRC "친구 챌린지" 패턴)
- 현재 등급 체계에 소셜 비교 레이어 추가 → 자발적 공유 유도

**③ 연중 이벤트형 회고 카드 (M22 기반 확장)**
- 월간 회고, x권 달성 기념일 자동 카드
- 연말 1회 → 연중 상시 바이럴 루프로 전환

### 5.2 Phase 7 후보 (시장성 높은 미구현 기능)

**④ 챕터별 진도 채팅방** (독창적 차별화)
- "3장까지 읽은 사람만 입장 가능한 스포일러 없는 토론방"
- 현재 그룹 채팅이 책 단위 피드와 분리된 구조를 활용해 진도 기반으로 세분화
- StoryGraph·Fable이 구현하지 못한 기능 → 강력한 차별점

**⑤ 오프라인 독서 모임 연결** (Phase 4 보류 항목)
- 온라인 그룹 → 오프라인 모임 스케줄링
- 한국 독서 커뮤니티 문화(북클럽, 독서 모임)와의 연결

**⑥ 딥러닝 추천** (사용자 1만 명 이후, Phase 7 보류)
- `user_event_log` 스키마가 M23에서 이미 준비됨 → 데이터 수집은 진행 중
